Возможности платформы

Всё, что нужно для управления школой — в одной системе

👥

Управление пользователями

5 ролей: супер-админ, директор школы, учитель, ученик, родитель. Профили с @username и настройками приватности.

📚

Уроки и предметы

Создание уроков, привязка к предметам и классам, материалы, преподаватель и аудитория.

📅

Расписание

Недельное расписание по классам, Bulk-создание слотов, цветовая кодировка по предметам.

📝

Домашние задания

Назначение, статусы (assigned → submitted → graded), загрузка работ, обратная связь и оценки.

💬

Сообщения

Личные и групповые диалоги, чаты по классам, поиск по истории сообщений.

🔔

Уведомления

Push-уведомления о новых заданиях, сообщениях, оценках и объявлениях. Настройка каналов.

📢

Объявления

Школьные и классные объявления, закрепление (pin), аудитория по ролям и классам.

🛡️

Жалобы и модерация

Система репортов (harassment, bullying, spam), рассмотрение и резолюция администрацией.

📊

Отчёты

Успеваемость по классам, посещаемость, статистика по учителям и предметам.

🌐

Мультиязычность

Поддержка 3 языков: Español, Deutsch, English. Легко добавить новые языки.

🔐

Безопасность

JWT-авторизация, ролевая модель доступа (RBAC), fine-grained permissions, rate limiting.

🏫

Управление школой

Многошкольная архитектура, классы и секции, предметы с цветовой кодировкой.

Архитектура

Модульная структура с чётким разделением ответственности

⚡ Бэкенд

  • Express + TypeScript + Prisma ORM
  • 17 модулей (schema → service → controller → routes)
  • JWT-авторизация + middleware (auth, validation, rate limit)
  • Ролевая модель: 5 ролей с fine-grained permissions
  • Prisma-схема с 18+ сущностями и связями
  • Seed-скрипты для тестовых данных

🎨 Фронтенд

  • Next.js 14 App Router + TypeScript
  • 23 страницы с роль-базированным доступом
  • Tailwind CSS + shadcn-style компоненты
  • i18n (es/de/en) с React Context
  • Zustand для state management
  • Адаптивный дизайн (mobile + desktop)
